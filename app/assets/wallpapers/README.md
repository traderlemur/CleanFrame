# Launcher wallpapers

The twenty-four entries in `SOURCES.json` each have a background JPEG, a thumbnail, a small blurred panel backdrop and a 4K clip in `../uhd/`. Four registered material JPEGs per image live in `../materials/`. All derived images retain the source photograph's terms.

Photo pages, authors and licence observations are in [asset sources](../../../docs/asset-sources.md). Generation instructions are in [asset generation](../../../docs/assets.md). Full-size originals remain outside the repository.
